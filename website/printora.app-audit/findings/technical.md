## 2. Key Architecture Verifications

### 2.1 Canonical URL Implementation
- **Status**: Verified in `src/app/layout.tsx` (`alternates: { canonical: "./" }`) and route-specific canonicals generated via `constructMetadata` in `src/lib/metadata.ts`.
- **Target Domain**: Normalized to `https://printora.calclabz.com/*`.
- **Impact**: Completely eliminates URL parameter duplicate indexing risks (`?ref=...`, `?utm=...`).

### 2.2 Strict HTTP Security Headers
- **Status**: Verified in `next.config.ts`:
  - `X-Frame-Options: SAMEORIGIN` (Clickjacking mitigation)
  - `X-Content-Type-Options: nosniff` (MIME sniffing prevention)
  - `Referrer-Policy: strict-origin-when-cross-origin`
  - `Strict-Transport-Security: max-age=63072000; includeSubDomains; preload`
  - `Permissions-Policy: camera=(self), microphone=(), geolocation=()`
  - `Content-Security-Policy: default-src 'self' ...`
  - `poweredByHeader: false` (Suppresses server framework disclosure)

### 2.3 Robots.txt & Sitemap Discovery
- **Status**: Valid dynamic routes at `/robots.txt` and `/sitemap.xml`.
- **Crawlers Allowed**: Explicitly configured for Googlebot, Bingbot, Applebot, DuckDuckBot, ChatGPT-User, GPTBot, PerplexityBot, ClaudeBot, Google-Extended, Amazonbot, anthropic-ai, Bytespider, CCBot, Meta-ExternalAgent.
- **Sitemap**: Clean index of 30 content URLs with priorities ranging from 1.0 (Home) to 0.7 (Guides), updated `lastmod: 2026-10-24`.
